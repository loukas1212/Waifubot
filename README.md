# Waifubot

Fork de Loukas Community Bot (dev version) prévue pour avoir des commandes de waifu

---

## Installation

1. cloner le script et installer python
2. créer un venv et installer le contenu de requirements.txt avec `pip install -r requirements.txt`
3. créer un `.env` et ajouter la ligne `BOT_TOKEN = "votre_token_ici`
4. lancer `python3 main.py` et prier pour que ça marche
